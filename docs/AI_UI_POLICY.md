# PennyPal AI UI Policy

- The in-app feature is presented as **PennyPal Assistant**.
- Provider and model names are implementation details and are not shown in the student-facing UI.
- The implementation uses Firebase AI Logic with a supported generative model behind the PennyPal Assistant service.
- AI provider/model details may be documented for the project report and technical review, but should not be exposed as a product label unless the team intentionally chooses to disclose them.
- If the live AI request fails, the app must remain usable and should provide a clear, product-level response rather than pretending a failed request was generated by the AI service.
- During local Android emulator testing, Firebase App Check debug tokens must be registered in Firebase Console before an enforced AI request can be accepted.
