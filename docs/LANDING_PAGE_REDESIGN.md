# PennyPal Landing Page Redesign

The landing page has been rebuilt as a responsive, product-style introduction rather than a single centered welcome card.

## Changes
- One PennyPal logo/wordmark in the landing header.
- Reworked PennyPal mark using a navy/gold growth-oriented monogram.
- Premium dark hero section with clear primary and secondary actions.
- Responsive dashboard preview built from Flutter widgets (no fake screenshot dependency).
- How-it-works section covering Record, Plan and Grow.
- Feature section covering expenses, budgets/alerts, savings goals, reports/trends, learning and the assistant.
- Final call-to-action and concise footer.
- Mobile layout collapses cleanly while preserving the same hierarchy.
- Header links scroll safely to page sections.
- Existing Sign In and registration routes are preserved.
